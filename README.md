# Cloudflare Workers AI Llama 3 Inference

Demonstrates invoking Meta Llama 3 on Cloudflare Workers AI using low-latency edge inference via its REST API. Includes token-based authentication, request payload structure with system/user messages, and response latency measurement.

## Language

`python`

## How to Run

export CLOUDFLARE_ACCOUNT_ID="your_id" CLOUDFLARE_API_TOKEN="your_token"
python main.py "Why is edge AI beneficial?"
